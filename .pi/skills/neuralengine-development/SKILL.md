# NeuralEngine Development adapter

This Pi-compatible adapter provides a portable lowercase skill name because
the canonical skill's frontmatter uses the display name `NeuralEngine Development`,
while Pi skill names follow the lowercase letters/numbers/hyphens format.
It is not a semantic fork.

For every engineering task in this repository:

1. Read `AGENTS.md`.
2. Read `.claude/skills/neuralengine/SKILL.md` completely and follow it as the
   canonical NeuralEngine Development contract.
3. Read `VISION.md`, `CONTEXT.md`, `memory/project-state.md`,
   `docs/architecture.md`, and `docs/conventions.md` when the task requires
   project context or architectural decisions.

Do not replace, paraphrase, or locally reinterpret the canonical skill.
